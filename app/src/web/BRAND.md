# Brand assets

CFC Bank is a **fictional institution invented for this demo**. The mark below
is an original geometric device — a shield with three ascending bars — drawn
from scratch by `tools/make_brand.py`. It is not traced from, derived from, or
intended to resemble the logo of any real bank or organisation.

All data in this application is synthetic and generated by `data/`; nothing
here originates from a real financial institution.

## Palette

| Token | Value | Use |
|---|---|---|
| `--brand` | `#034694` | top bar, primary buttons, accents, rules |
| `--brand-deep` | `#012a5e` | hover states, links |

The per-layer IQ colours (`--work`, `--fabric`, `--foundry`, `--web`) are
unchanged — they identify the four intelligence layers, not the bank.

The semantic warning colour is `#b91c1c`, kept deliberately distinct from the
brand so a breached guardrail on the offer flyer still reads as a warning
rather than as branding. Under the old red brand the two were the same colour
and the distinction was invisible.

## Files

| File | Use |
|---|---|
| `cfc-bank-logo.png` | 512px, brand blue on transparent — sign-in card |
| `cfc-bank-logo-white.png` | 512px, mono white on transparent — blue top bar |
| `favicon.png` | 64px, brand blue — browser tab |

The bars are knocked out of the shield to full transparency rather than painted
white. The white variant sits on the brand-blue top bar, so the bar shows
through the bars and the mark keeps its structure instead of flattening into a
solid blob at 26px.

## Regenerating

```bash
cd app/src/web
python tools/make_brand.py
```

Geometry and colour both live in that script — change `BRAND`, `shield_outline()`
or `bars()` and re-run. All three files are rewritten from the same source, so
the variants can never drift apart.
