# Work IQ evidence synthesis playbook

Search correspondence in focused passes: branch capacity, competitor
pressure, payment shock, advisor workflow, broker ownership, pricing
escalations, executive decisions, and compliance. Include email, Teams, and
meeting records where available.

For each material point, retain the source type, author role, date, topic, and
whether it is a proposal, decision, condition, or observation. Summarize
decisions separately from concerns and requests. Then ask Fabric IQ whether a
numeric claim is corroborated. If it is not corroborated, report the observed
statement and the governed result side by side.

Avoid broad searches that return unrelated mailbox noise. Small, focused
retrievals improve evidence quality and citation traceability.
